🚀 Overview

This is a simple, interactive Character Counter Web App built using HTML, Tailwind CSS, and JavaScript.

It allows users to type a message and see:

Live character count

Progress bar indicating text length

Warning message if the character limit is exceeded

The app is designed with a centered, stylish box, rounded borders, shadow effects, and smooth animations, providing a modern and user-friendly interface.

🎯 Features

Live Character Counter: Updates as you type.

Progress Bar: Visually represents how close you are to the 200-character limit.

Limit Warning: Shows a warning message if the character limit is exceeded.

Responsive & Modern Design: Works perfectly on all screen sizes with a gradient background and shadowed container.

Smooth Animations: Fade-in effect for the box and warning messages.

🛠️ Technologies Used

HTML5 – Structure of the web page

Tailwind CSS – For responsive styling and design

JavaScript – Dynamic character counting and progress bar updates
